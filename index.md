# ORI Annotations Project Home

This is a toolkit for annotations and review sync tools. The focus is on simplifying how annotations and notes within a review can easily get to the artists, ideally in the tool that they typically do their work in.

This project is split into four main parts:

1. [Code for loading and saving annotations]({{ site.baseurl }}{% link ORIAnnotations.md %})
    * [Annotation test charts]({{ site.baseurl }}{% link testchart/README.md %})
2. Common tools for syncing, such as recording and playback of sessions:
    * [Sync Recorder]({{ site.baseurl }}{% link sync_recorder/README.md %})
    * [Sync Viewer]({{ site.baseurl }}{% link sync_viewer/README.md %})
    * [Sync Testing and Utilities]({{ site.baseurl }}{% link sync_test/README.md %})
3. [xStudio Sync plugin]({{ site.baseurl }}{% link xstudio_plugin/ori_sync/README.md %})
4. [OpenRV Sync plugin]({{ site.baseurl }}{% link rvplugin/ori_sync/README.md %})
