**Group 3 outcome (2026-08-10): one guard retired (`_local_scrub_active_until`, dead code), one already-complete (`is_master` remnant), seven left in place.** The original replacement table (design.md, written 2026-08-07/08) assumed each guard was a single-purpose position/structure echo suppressor that the lease would make redundant. Re-reading the current code found that assumption no longer holds for most of them: the codebase absorbed substantial hardening from `fix-visibility-authority-bypass` and related work between the plan being written and this pass, and several guards picked up second jobs (local self-write suppression, actor-model settling) that have nothing to do with broadcast authority. Retiring the rest would need either accepting the identified risks or splitting the mixed-purpose guards into separate single-purpose mechanisms first — deliberately out of scope for what this task list called a "pure removal commit." Revisit as a dedicated follow-on if the remaining guards are worth the surgery.
